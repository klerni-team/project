# Продолжение обучения на всех пригодных аннотациях
Запуск: https://github.com/klerni-team/project/actions/runs/43635573640

Продолжаем с heads.safetensors из релиза interiors-trained-43634325158. Веса 3 классов поверхностей и 8 исходных материалов копируются без переинициализации. Добавлены 9 классов материалов с новой инициализацией: paint, wallpaper, granite_or_marble, linoleum, metal, glass, fabric, plastic, carpet_or_rug. Неоднозначные исходные классы сохранены отдельными.

Модуль извлечения признаков Mask2Former заморожен. Это продолжение обучения выходных слоёв, не полное дообучение всех весов.

## Полный охват
Проверяется каждая из 5146 записей реестра. Отсутствующие фото, несовпадения хешей, некорректные размеры/геометрия/ориентация и отсутствие подходящих целевых пикселей исключаются с причиной в coverage.json.
Существующие 64 проверочных COCO-снимка остаются в проверке; остальные COCO val2017 резервируются. OpenSurfaces делится по исходной странице фото детерминированно, около 10% остаётся для проверки. Идентификаторов зданий нет.
Точные дубликаты исключаются из обучения. Близкие перцептивные хеши между обучением и проверкой исключаются.
OpenSurfaces растрируется по исходным треугольникам, а не соединением несортированных вершин. Конфликтующие и неразмеченные пиксели игнорируются. Ориентация EXIF, отличная от 1, требует сверки и не используется автоматически.
Локальные проверки геометрии подтвердили растрирование треугольника, игнорирование неразмеченных областей и конфликтов классов.

Каждый пригодный обучающий снимок участвует в каждой из 20 эпох. Для ускорения CPU используется до 1024 размеченных пикселей из карты 64x64 на фото. Признаки кэшируются на диске.
В конце проверяется совпадение множества действительно использованных ID с полным выбранным обучающим набором.
Это не означает использование каждого исходного пикселя или достижение заданного качества.

## Результаты
После успешного окончания GitHub Release interiors-trained-<run_id> содержит:
- interiors-all-heads.tar.gz: лучшие и последние веса голов, конфигурацию и состояние оптимизатора;
- training-report.json: метрики, охват и ограничения;
- history.json и learning-curves.png: динамику обучения;
- split.json и coverage.json: разбиение и статус каждой записи.

Проверочная выборка и набор классов расширены: итоговый mIoU нельзя напрямую сравнивать с первым пилотом.
IoU относится только к размеченным пикселям 64x64. Проверочная выборка выбирает лучшую эпоху; независимого финального теста ещё нет.
Линолеум представлен небольшим числом исходных примеров. Проводка, штукатурка и цвет не обучаются этим скриптом.
Лицензионные ограничения и незавершённая проверка прав остаются прежними.

## Использование
Сохраните исходный model-package рядом с распакованным trained-all:
```bash
python construction-dataset/model/predict_all.py --base model-package --adapter trained-all --image interior.jpg
```
Требуются train_all.py и train_stage1.py из этой же папки.
Для запуска обучения: распакуйте предыдущий adapter в previous/, данные в training-data/, базовую модель в model-package/ и запустите train_all.py.
