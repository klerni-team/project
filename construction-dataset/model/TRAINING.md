# Первый этап дообучения
Запуск: https://github.com/klerni-team/project/actions/runs/43634325158

Архитектура: предобученный Mask2Former Swin Small с замороженным модулем извлечения попиксельных признаков; два новых обучаемых слоя 1×1 для поверхностей и материалов. Исходные веса не перезаписываются. Это перенос обучения с обучением выходных слоёв, а не полное дообучение всех параметров.

Параметры: seed 42, AdamW, lr 0.001, weight_decay 0.01, 20 эпох, до 256 обучающих и 64 проверочных фотографий, CPU. Изображения приводятся к 256×256, разметка — к 64×64 методом ближайшего соседа. Размеченные пиксели участвуют в loss; неизвестные игнорируются (255), не считаются фоном.

Поверхности: wall, floor, ceiling.
Материалы: concrete, tile, wood, carpet, brick, panel, marble, stone.
Разметка материалов взята из существующих масок COCO-Stuff; свойства скрытого под отделкой материала по фото не устанавливаются. Цвета, проводка, штукатурка и линолеум в этом этапе не обучаются.

## Данные и проверка
Обучение использует COCO train2017, проверка — val2017 с совпавшими автором и лицензией в существующем аудите.
Редкие материалы включаются через циклическую выборку классов. Проверяются SHA-256 фотографий и масок, совпадение размеров.
Между выборками исключаются совпадения SHA-256 и близкие перцептивные хеши (63 бита, расстояние ≤6).
Идентификаторов зданий нет: разделение строго по зданиям не подтверждено.
Проверочные данные используются для выбора лучшей эпохи по loss; это не независимый финальный тест.
IoU измеряется только на размеченных пикселях сетки 64×64. Метрики нельзя переносить на всё изображение или все строительные объекты.

## Запуск
Зависимости и базовые веса описаны в README.md.
Распакуйте interiors-restored.tar.gz в training-data/ и базовые веса в model-package/.

```bash
python construction-dataset/model/train_stage1.py --data training-data --base model-package --epochs 20
```

Результат: trained-interiors/heads.safetensors, adapter_config.json, split.json, history.json, training-report.json и SHA256SUMS.
Архив обученных слоёв публикуется в GitHub Release interiors-trained-<run_id> после успешного окончания. Для работы нужны также исходные веса Mask2Former.

```bash
python construction-dataset/model/predict_stage1.py --base model-package --adapter trained-interiors --image interior.jpg --output prediction-stage1
```

Выходные маски surface.png и material.png используют ID из adapter_config.json; 255 означает неизвестное.
Прогноз ограничен поверхностями, найденными базовой ADE20K-моделью. Дополнительно применяется порог softmax 0.6, который пока не калиброван; качество этой полной схемы отдельно не оценено.
Результат экспериментальный, требует проверки человеком.

Лицензия исходных весов остаётся other; коммерческие права не подтверждены.
Часть обучающих фотографий ещё требует индивидуальной проверки авторства и лицензии; обучение не закрывает эту задачу.
