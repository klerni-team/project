# Контакты организаций с Яндекс Карт по нишам

Собирает организации города по 61 нише (11 групп) через официальный
«API Поиска по организациям» Яндекса и пишет отдельный CSV на каждую нишу.
Страницы yandex.ru/maps не скрапятся.

## Ключ API

1. Войдите в [Кабинет разработчика](https://developer.tech.yandex.ru/) и нажмите «Подключить API».
2. Выберите «API Поиска по организациям», заполните форму и получите ключ (активируется в течение ~15 минут).
3. Передайте ключ через переменную `YANDEX_SEARCH_API_KEY` или флагом `--api-key`. Можно положить
   `YANDEX_SEARCH_API_KEY=...` в `.env` в корне репозитория: его читает `npm run contacts`, а при прямом
   запуске через `node` нужен флаг `--env-file-if-exists=.env` (см. пример ниже).

## Запуск

```sh
npm run contacts -- --list                          # ниши с номерами, без сети
npm run contacts -- --city "Казань"                 # все ниши
npm run contacts -- --city "Казань" --niche 1 --niche 04-02 --niche "автошкол"
node --env-file-if-exists=.env tools/yandex-contacts/cli.ts --city "Казань" --max-requests 400 --delay 1000
```

| Флаг | Что делает |
| --- | --- |
| `--city` | город; его границы берутся из API (`type=geo`) |
| `--out` | папка для файлов, по умолчанию `contacts/<город>/` |
| `--niche` | номер группы (`4`), ниши (`04-02`) или часть названия; можно несколько раз |
| `--bbox lon1,lat1~lon2,lat2` | своя область поиска вместо границ города |
| `--delay` | пауза между запросами, мс (по умолчанию 500) |
| `--max-requests` | лимит запросов к API за запуск; ответы из кеша не считаются |
| `--page-size` | результатов на запрос, 1..500 (по умолчанию 50) |

Код выхода: 0 — готово, 1 — ошибка (аргументы, город не найден, API отклонил запрос с кодом 4xx — проверьте параметры), 2 — остановлено по квоте, лимиту или сбою сети/сервера, можно продолжить.

## Что в файлах

`contacts/<город>/01-04 Электрики, сантехники, отопление и водоснабжение.csv` и т. д. —
CSV в UTF-8 с BOM, разделитель `;` (открывается в Excel двойным щелчком). Колонки:
название, телефоны, сайт, адрес, категории, часы работы, широта, долгота, id Яндекса,
ссылка на карточку `https://yandex.ru/maps/org/<id>`, запросы, по которым организация найдена.
Внутри ниши организация встречается один раз. Ниша без результатов получает файл с одним заголовком.

`contacts/<город>/.cache/` — сохранённые ответы API (без ключа). Удалите папку, чтобы получить свежие данные.

## Ограничения

- **Квота.** Бесплатный ключ даёт немного запросов в сутки, а полный обход города — сотни и тысячи
  запросов. Ответы кешируются, поэтому при 403/429 или `--max-requests` программа сохраняет собранное
  и останавливается; та же команда завтра продолжит с места остановки, не тратя запросы повторно.
  403 означает и неверный ключ — проверьте его, если остановка случилась сразу.
- **Размер страницы.** По умолчанию 50 результатов на запрос. По документации API допускает до 500
  (`--page-size 500`), что расходует квоту до 10 раз медленнее, но это не проверено живым запросом —
  попробуйте на своём ключе. Размер страницы входит в ключ кеша: после его смены ответы запрашиваются заново.
- **Потолок выдачи.** API отдаёт не больше ~1000 результатов на запрос. Если в области найдено
  больше, она делится на 4 части и обходится заново (до 4 уровней). Если даже мелкий участок
  упирается в потолок, программа предупредит, что список ниши может быть неполным.
- **Запросы.** Каждая ниша — несколько поисковых фраз (видны в `--list`, правятся в `niches.ts`).
  Поиск нечёткий: в выдачу попадают и соседние категории, проверяйте колонку «Категории».
- **Условия использования.** Данные API подчиняются условиям Яндекса. Бесплатный тариф не разрешает
  хранить полученные данные — для этого нужна коммерческая лицензия. Проверьте актуальные условия
  на developer.tech.yandex.ru и в договоре сами, прежде чем сохранять и использовать результаты.
